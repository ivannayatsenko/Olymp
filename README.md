Web-застосунок обліку замовлень та товарів інтернет-магазину «Олімп»

Web-застосунок «Олімп» призначений для централізованого управління каталогом товарів, складськими залишками та замовленнями інтернет-магазину. Система забезпечує зручний вибір товарів і оформлення покупок для клієнтів, а також рольовий доступ та відстеження статусів замовлень для адміністрації.

«Основні функції»
1. Авторизація та аутентифікація користувачів за ролями. 
2. Ведення каталогу товарів (додавання, редагування, видалення, ціна, наявність). 
3. Перегляд та фільтрація товарів покупцем. 
4. Формування кошика та створення замовлення. 
5. Зміна статусу замовлення (Нове, Оброблено, Відправлено, Скасовано). 
6. Перегляд історії замовлень у кабінеті користувача.
